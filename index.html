01 / 按需求找入口

每家都有适用条件

带来源的 JSON ↗

显示 8 项服务

TokenDos ↗

会员共享

比较供应节点，也能消费或供应闲置会员会话算力。

值得关注

供应方独立报价、站内活动、公开 USD 报价接口，以及可查看的在线鹈鹕测试与历史结果。共享机制允许用户参与算力供应和按量结算。鹈鹕记录反映特定测试，不能单独证明模型身份或整体可靠性。

选用条件

来源多，需要自行筛选；SESSION 依赖双方 Agent 与在线供应端。2026-10-09 15:14 UTC 的公开 CODEX_SESSION 与 CLAUDE_SESSION 查询均为 0 条，实时供给需确认。聚合各项最低价可能来自不同供应方，预算需按所选节点核算。平台临时保留近期请求响应，供应方可能读取会员会话代码。公开条款注明默认并发为 1、当前不开票。

机制与数据处理价格与运营条款报价快照节点与测试

OpenRouter ↗

路由控制

适合把提供商选择与数据策略写进请求配置。

值得关注

指定、排除提供商，配置故障回退；按价格、延迟或吞吐设置路由偏好，并提供数据收集与 ZDR 策略筛选。

选用条件

充值平台费用和 BYOK 规则影响预算；限制提供商或数据策略会减少回退选择。延迟、吞吐偏好需要结合实时供给判断。

提供商路由费用规则

AIHubMix ↗

多模态

适合集中接入文本、图像、视频与语音等能力。

值得关注

多模态接口资料，Claude / Gemini 原生接入说明，以及模型映射、回退和应用生态。

选用条件

能力依模型和接口而异。Anthropic 兼容接口标为 Beta，应与 Claude 原生接口分别核对；应用生态优惠排除 Claude。

功能文档Claude 原生接口应用优惠

ZenMux ↗

用量观察

适合多协议调用和异常费用观察。

值得关注

OpenAI、Anthropic 与 Vertex 接入，调用用量明细，以及按模型和原因查看的异常赔付记录。

选用条件

PAYG 与 Builder 适用场景不同；Builder 限个人开发学习，并有周额度及速率限制。完整赔付阈值与覆盖条件需进一步确认。

接入和用途订阅规则赔付记录

AIGoCode ↗

编程套餐

适合规律的编程用量与团队额度管理。

值得关注

四周订阅、每周额度刷新、余额接续，以及团队成员、Key 与成本管理。

选用条件

按各周实际利用率计算套餐价值；不同分组有计价和工具限制，部分仅允许 Claude Code。平台美元额度需按分组价格换算。

套餐方案分组与价格退款规则

DeepSeek 官方 API ↗

厂商直接接入

适合主要使用 DeepSeek，并直接按厂商规则计费。

值得关注

官方模型、能力与计费说明，可作为 DeepSeek 成本比较基准；缓存、峰谷价格和别名规则有公开文档。

选用条件

模型范围集中于 DeepSeek；需要 Claude、GPT 或 Gemini 时另接入口。版本、别名映射与计价会变化，应保留日期。

官方模型和定价

硅基流动 SiliconFlow ↗

模型云服务

适合多模态、向量与重排序接入，以及开票或专属部署需求。

值得关注

OpenAI / Anthropic 对话协议，公开账户等级和逐模型限流规则；提供开票条件、预留实例和私有化部署方案。

选用条件

限流在账户级而非 Key 级计算；免费模型需实名认证。仅已消费金额可开票，认证主体决定抬头与类型。专属部署的隔离能力不能当作普通共享 API 的保障。文档核对日期 2026-10-10，未进行调用或开票实测。

平台能力限流规则开票条件

智谱 GLM Coding Plan ↗

官方编程套餐

适合在支持的编程工具中按周期使用 GLM。

值得关注

公开输入、缓存与输出的积分抵扣系数、非高峰模型抵扣规则，以及视觉理解、搜索和网页读取等 MCP 能力。

选用条件

5 小时与周限额同时生效，模型和 MCP 共用额度；限指定工具与套餐端点，用尽不接续余额。禁止多人共享、倒卖和中转。订阅自动续费且不退款，当前取消续订需至少提前 3 天。Anthropic 兼容接口使用 GLM 模型。文档核对日期 2026-10-10，未订阅或调用实测。

未缓存输入与缓存读取量互不重叠；缓存未命中时填入普通输入价。报价应已含分组倍率，并按所选币种的 1:1 现金兑换口径填写。「其他项目」为整个任务量的合计，可补充缓存写入、工具与失败重试等费用。赠送额度假定全部满足条件并用完，充值附加费按购买额度加收。估算未自动包含最低充值、最低手续费、税费、汇兑和未填入的项目，也不适用于周期套餐。

计算在当前浏览器完成；参数会写入你主动分享的链接，任何收到链接的人都能看到报价与用量。导出结果是预算估算，不是扣费或实测证明。
